A small program that writes exactly one word (6 characters) to `/output/entry.txt`: the single word that describes the boss — "Parrot". No phrase, no caption, no explanation: the boss who repeats your idea in the afternoon meeting as if it just hatched in his own head.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
